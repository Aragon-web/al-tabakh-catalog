About

Al-Tabakh Premium Catalog alpha v2
A serverless product catalog with built-in admin panel.

Deployment: Commit to GitHub and enable GitHub Pages, or upload to any static hosting (Netlify, Vercel, Cloudflare Pages).
Setup: Configure GitHub credentials in Settings → GitHub Sync, then use "Save & Sync" to publish changes.
Security: For production, replace the client-side auth with a proper backend.
